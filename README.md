# AuroraPlay 下载

此仓库用于公开分发 AuroraPlay 的 Windows 安装包、版本说明和 SHA-256 校验文件。播放器源码保留在私有仓库。

## 当前状态

本仓库尚未发布新的验收安装包，当前没有可下载版本。历史 v2.1.0 发布产物仍保留在原私有仓库，未复制到这里。

通过安装、启动、播放、重启及升级数据保留验收后，安装包与校验文件将发布在 [Releases](https://github.com/Howard9088/auroraplay-releases/releases)。对应版本说明会列明 Windows 要求、变更及升级注意事项。

本仓库不保存源码、授权私钥、个人数据或支付凭据。
